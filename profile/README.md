## Projects

- [Tainted](https://github.com/lua-wow/Tainted) — minimalistic UI replacement.
- [Filger](https://github.com/lua-wow/Filger) — minimalistic aura and cooldown tracker.
- [oUF_AuraTrack](https://github.com/lua-wow/oUF_AuraTrack) — raid-frame aura tracking for oUF.
- [oUF_RaidDebuffs](https://github.com/lua-wow/oUF_RaidDebuffs) — raid-frame dispellable-debuff icons for oUF.

## Dependencies

- [oUF](https://github.com/lua-wow/oUF) — unit frame framework (fork)
- [LibDispel](https://github.com/lua-wow/LibDispel) — dispel-type detection library
- [LibStub](https://github.com/lua-wow/LibStub) — library versioning stub
- [LibMobs](https://github.com/lua-wow/LibMobs) — instance NPC data library
- [TaintLess](https://github.com/lua-wow/TaintLess) — FrameXML taint fixes
- [oUF_Atonement](https://github.com/lua-wow/oUF_Atonement) — oUF element
- [oUF_TargetIndicator](https://github.com/lua-wow/oUF_TargetIndicator) — oUF element
- [oUF_Tempest](https://github.com/lua-wow/oUF_Tempest) — oUF element
- [dispels](https://github.com/lua-wow/dispels) — dispel announce module
- [interrupts](https://github.com/lua-wow/interrupts) — interrupt announce module
- [screenshots](https://github.com/lua-wow/screenshots) — auto screenshot module
